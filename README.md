# chloecouzens.com

Single-page site for Chloe Couzens, performance coach for children and young adults.

Everything lives in `index.html`. It has no build step and no dependencies apart from Google Fonts.

## Before it goes live

Search the file for `class="todo"`. Each one marks a fact only Chloe can supply (dates, sport and caps, degree, location, email, a testimonial). They show up on the page as yellow highlighted blocks so none can be missed.

## Preview locally

```
python3 -m http.server 8765
```

Then open http://localhost:8765.

## Publishing

GitHub Pages: Settings > Pages > Deploy from branch > `main` / root. On a free account the repo must be public for Pages to work.
